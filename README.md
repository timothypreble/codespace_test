# codespace_test
testing code space for interviews

## T-SQL interview questions for Microsoft SQL Server 16

### Easy
1. How would you use `TOP`, `ORDER BY`, and `OFFSET ... FETCH` to return the 10 most recent orders in SQL Server 16?
2. What is the difference between `ISNULL()` and `COALESCE()` in T-SQL, and when would you prefer one over the other?

### Medium
3. Write a query using `ROW_NUMBER()` to return the latest order per customer, and explain why this is often better than a correlated subquery.
4. In SQL Server 16, how would you parse JSON input using `OPENJSON` and load it into a relational table with proper data types?

### Hard
5. Design a strategy for implementing and querying a SQL Server 16 ledger table for an audit-sensitive financial dataset, including how you would verify data integrity over time.
